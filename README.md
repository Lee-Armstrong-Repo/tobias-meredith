# Tobias Meredith

Personal website for tattoo artist Tobias Meredith.

## Pages

- `/` — landing
- `/about` — about
- `/work` — portfolio
- `/booking` — consultation enquiry

## Develop

```bash
npm install
npm run dev
```

## CMS setup

This project is wired for Sanity so Tobias can manage:

- blog posts
- work / portfolio items

To connect it:

1. Create a Sanity project.
2. Copy `.env.example` to `.env.local`.
3. Fill in the Sanity project id and dataset.
4. Run `npm run dev` and open `/studio`.

Until Sanity is connected, the site falls back to the placeholder content already in the repo.

## SEO notes

- Static App Router pages with per-route metadata
- `sitemap.xml` and `robots.txt` generated by Next.js
- blog index plus individual blog post URLs
- `next/image` for optimized photos, including Sanity-hosted images
- Update `content/site.ts` (`url`, email, Instagram) before going live
