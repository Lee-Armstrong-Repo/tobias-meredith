# Tobias Meredith

Personal website for tattoo artist Tobias Meredith.

## Pages

- `/` — landing
- `/about` — about
- `/work` — portfolio
- `/booking` — consultation enquiry

## Develop

```bash
npm install
npm run dev
```

## Add portfolio images

See [`content/README.md`](content/README.md). Drop files into `public/work/` and register them in `content/work.ts`.

## SEO notes

- Static App Router pages with per-route metadata
- `sitemap.xml` and `robots.txt` generated by Next.js
- `next/image` for optimized photos once real jpg/webp assets replace SVG placeholders
- Update `content/site.ts` (`url`, email, Instagram) before going live
