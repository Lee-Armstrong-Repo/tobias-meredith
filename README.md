# Tobias Meredith

Personal website for tattoo artist Tobias Meredith.

## Pages

- `/` — landing
- `/about` — about
- `/the-studio` — studio / Victims of Ink
- `/work` — portfolio
- `/blog` — notes
- `/booking` — consultation enquiry
- `/studio` — Sanity CMS (editors only)

## Develop

```bash
npm install
npm run dev
```

Production-like locally:

```bash
npm run build
npm start
```

## Deploy (Bitbucket → GoDaddy)

See **[DEPLOY.md](DEPLOY.md)** for Node.js App setup, env vars, Sanity CORS, and release steps.

## CMS setup

This project is wired for Sanity so Tobias can manage:

- blog posts
- work / portfolio items

To connect it:

1. Create a Sanity project (or use the existing one).
2. Copy `.env.example` to `.env.local`.
3. Fill in the Sanity project id and dataset.
4. Run `npm run dev` and open `/studio`.
5. Add CORS origins for localhost and the production domain (see DEPLOY.md).

Until Sanity is connected, the site falls back to the placeholder content already in the repo.
